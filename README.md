# Pet Care System 🐾

A beginner-friendly Python project built using **Object-Oriented Programming (OOP)** that manages pet details in a simple, structured, and meaningful way.

This project is designed to store important pet information such as name, type, age in months, gender, and owner details, while also allowing the user to select **multiple care services** for the same pet. It is a small project, but it reflects how even basic programming concepts can be used to model a real-world system with clarity and logic.

---

## A Small System With a Real Purpose

Pet care is not always about one single service.  
A pet may need **grooming, vaccination, and a health checkup** at the same time.

That idea inspired this project.

Instead of creating a one-service-only program, this system was designed in a more realistic way — where one pet can have multiple selected services, and every detail is handled through proper input validation and OOP structure.

This project is simple enough for beginners to understand, yet practical enough to feel connected to real-life use cases. 

---

## Features

- Add pet details such as:
  - pet name
  - pet type
  - age in months
  - gender
  - owner name
- Select **multiple services** for the same pet
- Prevent duplicate service selection
- Validate user input to avoid invalid or empty values
- Display all stored pet details in a clean format
- Repeat the process for multiple pets

---

## Services Available

This system currently supports:

- Vaccination
- Grooming
- Health Checkup

A user can choose one or more of these services for the same pet.

## OOP Concepts Used

This project was created to practice and apply important OOP concepts in Python:

- **Classes and Objects**
- **Constructors**
- **Instance Attributes**
- **Methods**
- **Lists for storing objects and services**
- **Object interaction**

The project helped demonstrate how classes can make a program more organized, reusable, and easier to expand in the future. 

---

## Project Structure

### `Pet` class
The `Pet` class stores all the important information related to a pet:
- pet name
- pet type
- age in months
- gender
- owner name
- selected services

### `PetCareSystem` class
The `PetCareSystem` class manages the complete workflow of the program:
- taking user input
- validating input
- selecting multiple services
- storing pet objects
- displaying pet details
- repeating the system for the next entry

---

## Input Validation

To make the project more practical and user-friendly, validation has been added for:

- Empty input fields
- Age in months
- Gender values
- Valid service choices
- Duplicate service selection

This makes the program more reliable and prevents wrong entries from breaking the flow. Clear usage instructions and valid input handling are important parts of good beginner project documentation and usability.
---

## Sample Workflow

1. Enter the pet's name
2. Enter the pet type
3. Enter the pet age in months
4. Enter the pet gender
5. Enter the owner’s name
6. Select one or more services
7. View the stored pet details
8. Add another pet if needed
